# LUXDEV Data Analytics Portfolio

Welcome to my data analytics portfolio.

This repository contains practical projects developed through the LuxDev Data Analytics program, demonstrating my ability to work with data, analyse business problems, build dashboards, and communicate actionable insights.

The portfolio covers **SQL, PostgreSQL, Microsoft Excel, Power BI, DAX, data visualization, business intelligence, and analytical problem solving**.

The projects demonstrate a progression from foundational data work to more advanced analytical and business intelligence applications:

```text

        ↓
```
